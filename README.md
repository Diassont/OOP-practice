# 📊 Завдання 7 - Графічний додаток (На 5 балів)

## 📌 Опис завдання:
Необхідно розробити графічний додаток на Java з використанням Swing, який дозволяє користувачеві розраховувати повну енергію фізичного тіла за заданими параметрами: масою, швидкістю та висотою. Додаток повинен мати зручний графічний інтерфейс, що включає кнопки для виконання основних операцій, а також таблицю для відображення результатів обчислень.

## 📌 Етапи виконання:
1️⃣ Створення графічного інтерфейсу. <br>
2️⃣ Реалізація функціональності кнопок. <br>
3️⃣ Розрахунок енергії. <br>
4️⃣ Форматування даних. <br>
5️⃣ Реалізація таблиці для відображення результатів.

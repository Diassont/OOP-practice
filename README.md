# 📊 Завдання 6 - Паралельне виконання

## 📌 Опис завдання:
Завдання полягає в реалізації паралельної обробки елементів колекції для виконання різних операцій, таких як пошук мінімального та максимального значення, обчислення середнього значення, фільтрація за критерієм, а також статистична обробка даних. Для цього потрібно використовувати шаблон проектування Worker Thread для управління чергою завдань. Завдання додаються в чергу, а спеціальний обробник (Worker) виконує їх паралельно в окремих потоках, що забезпечує ефективне використання ресурсів і знижує час виконання.

## 📌 Етапи виконання:
1️⃣ Продемонструвати можливість паралельної обробки елементів колекції (пошук мінімуму, максимуму, обчислення середнього значення, відбір за критерієм, статистична обробка тощо).<br>
2️⃣ Управління чергою завдань (команд) реалізувати за допомогою шаблону Worker Thread.
